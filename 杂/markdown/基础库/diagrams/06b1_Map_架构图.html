单容器本质

  • 键+值直接存槽内：命中即取，无二次寻址
  • 没有 keys_ 数组 → 没有「第 i 个」、没有补位
  • 遍历序 = 槽位序（哈希决定，不确定）

add 家族语义表

  • add_new：断言不存在（意图最明确，优先用）
  • add / add_overwrite：已存在时保留 / 覆盖旧值
  • lookup_or_add / add_or_modify：惰性构造与原地修改
  • pop：取值同时删键

哈希副本之谜（实测澄清）

  • Map 全部槽型都不存哈希副本（比较时现算）
  • 字符串重复计算的开销走 _as 异型查找规避
  • Set 侧的 HashedSetSlot 才是存哈希的（见 06b2 图）
