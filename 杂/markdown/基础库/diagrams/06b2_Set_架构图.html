语义雷达需要更多地图可见空间。

Set = Map − value_buffer_

  • 槽里少一个 TypedBuffer&lt;Value&gt;（int 键省 4~8B/槽）
  • 接口全是单侧：contains / add / remove
  • 删除同样两行：槽留墓碑，无补位

槽选择谱系（编译期）

  • 默认 → SimpleSetSlot（最小通用）
  • std::string / StringRef / StringRefNull → HashedSetSlot（存哈希副本）
  • K* → IntrusiveSetSlot（状态编进指针）

哈希副本：Set 有，Map 无

  • HashedSetSlot 探测时先比 64 位哈希，拦下绝大多数不等
  • Map 无字符串特化——用 _as 异型查找规避重复计算
  • 同一个问题，两个库各给了一条路线
