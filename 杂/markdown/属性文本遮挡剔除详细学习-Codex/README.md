## 先记住一句话

`update_text_depth()` 在有文字请求遮挡测试时，把**当前帧**视口深度从 GPU 读到 `Instance` 拥有的 CPU 数组，然后把这份数组**借给**文字缓存；逐条文字是否绘制，稍后才由 `DRW_text_cache_draw()` 决定。
