## 30 秒速览

### 四个矩阵的关系

```
winmat   = P            （投影矩阵，唯一决定"透视"的地方）
viewmat  = V            （观察矩阵，把相机搬到原点）
persmat  = P × V        （合并后，世界坐标 → 裁剪空间）
persmatob = P × V × M   （再乘物体矩阵，物体坐标 → 裁剪空间）
```

### 执行顺序（从右往左读）

```
persmatob = P  ×  V  ×  M
            ↑     ↑     ↑
          最后   中间   最先
          投影   观察   物体变换
```

### 三类变换函数

| 函数 | 实现 | 适用矩阵 |
|------|------|----------|
| `transform_point(m, p)` | `m₃ₓ₃·p + T` | **仅仿射**（M、V） |
| `transform_direction(m, d)` | `m₃ₓ₃·d` | **仅仿射** |
| `mul_m4_v4(m, v)` | 完整 4×4 | **任意**（含 P） |
