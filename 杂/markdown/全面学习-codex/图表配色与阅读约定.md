# 图表配色与阅读约定

> 第二版阅读方式：先看教学注释代码，再看紧邻的机制推导；原始源码和基准行号放在折叠区。依赖入口链接到完整实现单元。源码一致性检查与内容复核分别记录。


颜色与文字共同表达语义，禁止仅靠颜色传达正确与错误。每篇正文至少四张图。图中的教学关系、编译依赖和实际状态推演分别标注。

| 语义 | 填充 | 描边 |
|---|---|---|
| 输入与接口 | #DBEAFE | #2563EB |
| 数据与存储 | #CFFAFE | #0891B2 |
| 类型与抽象 | #EDE9FE | #7C3AED |
| 计算与调度 | #FEF3C7 | #D97706 |
| 有效结果 | #DCFCE7 | #16A34A |
| 错误与失效 | #FEE2E2 | #DC2626 |

```mermaid
flowchart LR
  I["输入与接口"]:::input
  D["数据与存储"]:::data
  A["类型与抽象"]:::abstraction
  C["计算与调度"]:::compute
  R["有效结果"]:::result
  E["错误与失效"]:::error
  I -->|"提供"| D
  D -->|"解释"| A
  A -->|"执行"| C
  C -->|"成功"| R
  C -->|"违反约束"| E
  classDef input fill:#DBEAFE,stroke:#2563EB,color:#172554,stroke-width:2px;
  classDef data fill:#CFFAFE,stroke:#0891B2,color:#164E63,stroke-width:2px;
  classDef abstraction fill:#EDE9FE,stroke:#7C3AED,color:#3B0764,stroke-width:2px;
  classDef compute fill:#FEF3C7,stroke:#D97706,color:#78350F,stroke-width:2px;
  classDef result fill:#DCFCE7,stroke:#16A34A,color:#14532D,stroke-width:2px;
  classDef error fill:#FEE2E2,stroke:#DC2626,color:#7F1D1D,stroke-width:2px;
```

```mermaid
flowchart LR
  S["原始源码：保持内容"]:::input
  L["教学注释版与实现依赖"]:::abstraction

  V["验证报告：记录实际检查"]:::result
  S -->|"按行号对应"| L
  L -->|"推演"| M
  M -->|"区分已运行与未运行"| V
  classDef input fill:#DBEAFE,stroke:#2563EB,color:#172554,stroke-width:2px;
```

本轮采用flowchart作为统一图形语法；布局方向按内容选择LR或TB。边上的文字明确表示依赖、数据流或教学步骤，避免把include当作运行时调用。
