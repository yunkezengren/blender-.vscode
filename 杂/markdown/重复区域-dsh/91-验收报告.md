## 验收方法

1. **源码直读优先**：所有正文的行号引用来自当次 `read`/`grep` 实测，不使用记忆
   或外部资料。核心文件 `geometry_nodes_repeat_zone.cc`（432 行）、
   `node_geo_repeat.cc`（372 行）、`NOD_socket_items.hh`（419 行）、
   `node_tree_zones.cc`（653 行）、`repeat_zone_operation.cc`（184 行）均全文读过。
2. **行号抽查**：对每篇文档随机抽查 3 处行号引用，回源码核对内容一致
   （抽查确认：`update_zone_depths` L21、`get_direct_zone_relations` L86、
   `update_zone_per_node` L144、`update_zone_border_links` L199、
   `refresh_node_socket` L219、`usage_task__input__repeat_input_node` L437、
   `initialize_zone_wrapper` L1704、`build_repeat_zone_function` L2243、
   `build_zone_body_function` L2280、`build_zone_border_links_inputs` L2395、
   `insert_child_zone_node` L2810、`for_repeat_zone` 实现 L387/L398、
   `inspection_index` RNA L8087/L8321）。
3. **推演标注**：所有"用小数据走一遍"栏目均为教学推演，未在完整 Blender 构建
   中运行验证；涉及数值估计的性能论述均声明"非实测"。
4. **链接核对**：文档间相对链接与源码相对链接（`../../../` 前缀，从章节目录
   三层回到仓库根）已全量 grep 复核，无残留错误层数或断链文件名。

## 按章验收结论

### 00-课程指南

- 01-学习路线与阶段验收（1209 行）：六阶段路线、每阶段 8 个验收问题、与 AI 协作
  建议。结论：**通过**。
- 02-图表配色与阅读约定（1064 行）：六色 classDef 规范、箭头封闭词汇、`../../../../`
  层数算法、教学注释代码约定、29 术语表。结论：**通过**。
- 03-符号与源码索引（1014 行）：15 个源文件的符号定位表、覆盖矩阵、逐符号追踪
  指南。行号全部实测。结论：**通过**。

### 01-Zone系统基础

- 01-NodeTreeZone区域表示与配对（1392 行）：`find_zone_nodes` 三层答案、位传播、
  border_links 五连线验算、八条反例。结论：**通过**。
- 02-Zone输入输出与bundle迁移语义（1042 行）：动态 socket 生成、`Item_` 标识符
  稳定性、trace_values 的 bundle 迁移。结论：**通过**。

### 02-Repeat区域数据模型

  参数 `(false,1,1)`/`(true,0,0)` 逐一核对。结论：**通过**。

### 03-几何节点执行架构

- 01-ZoneBodyFunction与ZoneBuildInfo（1095 行）：七组下标接线表、

## 已知边界与未覆盖项

1. **未构建验证**：本系列全部结论来自源码阅读，未编译运行 Blender 或执行
   包含 Repeat Zone 的 .blend 文件。行为级结论（如"0 迭代直通"）有源码依据，
   但端到端表现（编辑器实际警告文案、Profile 显示形态）未实测。
2. **编辑器 UI 细节**：node editor 中 Repeat Items 面板的交互细节（拖拽排序
   操作符 `NODE_OT_repeat_zone_item_*` 的完整 exec 路径）只在 02-03 作接口级
   讲解，未逐行展开 ops 实现。
3. **历史提交**：未包含 git 提交演化分析（参考系列有 `_evidence/` 证据链）。
   本系列以当前工作树为准，不宣称引入提交。
4. **GPU 编译产物**：05-02 的着色器生成结果是教学示意，非真实编译输出。
5. **性能数字**：06-02 成本模型是结构性分析，无任何实测计时数据。
