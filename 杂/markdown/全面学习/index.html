02先知道每一层负责什么

场景层Depsgraph：变化传播、条件与操作调度
节点层LazyFunction / GraphExecutor：按需请求输入、组合节点组
表达式层Field / FieldContext：表达式在具体几何上下文中解释
批量执行层MultiFunction / Procedure：选择上的批量计算与临时值
基础设施Span · Vector · CPPType · VArray · IndexMask · SharedCache
i
三种图，三个问题

场景更新、节点按需求值、Field 表达式计算有不同职责。结构预处理的复用，也不等于把每个节点的结果跨次永久缓存。

05把一个提交读成一次设计训练

  1. 读说明，暂时遮住实现。用自己的话写出触发条件和失败原因。
  2. 提出两个候选方案。明确不变量、所有权、依赖以及预期成本。
  3. 对照 diff。每个关键改动都应能对应到一个问题或约束。
  4. 构造最小反例。测试必须能使旧方案失败，而不是只证明新实现能运行。
  5. 测量并复盘。记录硬件、编译选项、输入、误差与仍未覆盖的范围。
