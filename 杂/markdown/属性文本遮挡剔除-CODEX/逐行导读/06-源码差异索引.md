## 怎么使用注释代码导读

1. 先读详细解释，建立函数和数据流概念。
2. 打开对应文件的注释代码块，沿源码顺序阅读代码和中文说明。
3. 需要核对旧实现时，展开紧随其后的原始 `diff`。
4. 若要定位当前源码，以注释中的**新行号**打开工作区文件。旧行号只用于比较基准。

`+` 表示当前工作树新增，`−` 表示共同祖先中存在、当前版本删改的行。
空行、括号和源码原有英文注释保留原状，使代码仍能顺着读；关键表达式和参数会在相邻注释中解释。
完整数学和生命周期说明仍以专题章节为准。

## 版本边界

基准提交为 `bba93a5d6df198bcdb31b7b92cdbe514945ba2ad`。
本索引使用 `git diff <基准> --unified=3 -- 九个文件` 生成，因此同时包含已提交、已暂存和未暂存的修改。
源码继续编辑后，行号和 diff 可能漂移；应重新生成索引，并核对前五篇中依赖的具体参数和调用顺序。
