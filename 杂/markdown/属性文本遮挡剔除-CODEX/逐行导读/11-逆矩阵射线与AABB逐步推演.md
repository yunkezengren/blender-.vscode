# 逆矩阵、射线与 AABB：实例锚点逐步推演

> 目标是从 `local_anchor(0)` 走到代码里的 `exit_t`，明确每个量的坐标空间和单位。

## 1. 问题从哪里来

实例域值原来画在实例原点。原点如果位于自身网格内部，深度缓冲记录的是外表面，原点文本会被自己遮挡。当前实现用实例对象的轴对齐包围盒估计朝相机的前表面，将**用于投影和比较的锚点**移过去。

## 2. 先列空间表

| 变量 | 空间 | 几何意义 |
|---|---|---|
| `local_anchor` | 对象本地 | 实例文字原点，初始 `(0,0,0)` |
| `bounds->min/max` | 对象本地 | AABB 的两角 |
| `object_to_world` | 本地→世界 | 对象变换 |
| `world_center` | 世界 | 本地原点对应的位置 |
| `state.camera_position` | 世界 | 透视相机位置 |
| `toward_camera` | 世界方向 | 原点朝相机方向 |
| `world_to_object` | 世界→本地 | 对象矩阵的逆 |
| `local_direction` | 本地方向 | 与本地 AABB 同空间的射线方向 |
| `exit_t` | 无量纲参数 | 射线走到盒出口的比例 |

任何射线求交都必须让“射线原点/方向”与“盒子”处于同一坐标空间。

## 3. 具体矩阵和数字

对象本地到世界为 x 轴缩放 2，再平移 3：`world_x=2·local_x+3`。相机世界 x=13，对象原点世界 x=3。所以朝相机世界方向为 10。逆矩阵处理**方向**只除以 2，得到本地方向 5。

设本地盒 x∈[-1,1]，y,z 都覆盖原点。射线 `P(t)=0+t·5`。朝相机出口 x=1，对应 `t=0.2`。代码将本地锚点改为 `0+0.2·5=1`，世界位置为 `2·1+3=5`。相机在 `t=1` 位置 `0+1·5=5` 本地，映射到世界 13。锚点因此在相机之前。

如果把方向先归一化成本地 1，`exit_t` 将变成 1，便不再对应“原点到相机的比例”。当前实现刻意不归一化透视方向，才能用 `exit_t<1` 判断盒出口是否在相机之前。

## 4. 逐轴 slab 求交

AABB 的每一轴给一个允许的 t 区间。对 x：

```text
t_x0 = (min_x - origin_x) / direction_x
t_x1 = (max_x - origin_x) / direction_x
```

方向负时进入/离开先后反过来，因此取 `min(t_x0,t_x1)` 作为该轴进入参数，`max(...)` 为该轴离开参数。三轴的进入参数取最大，离开参数取最小：

```text
t_enter = max(x_enter, y_enter, z_enter)
t_exit  = min(x_exit,  y_exit,  z_exit)
```

若 `t_enter>t_exit`，三个轴约束没有公共区间，射线不命中。`isect_ray_aabb_v3_simple` 的实现正用这种 min/max 组合，并把返回指针的最后一个参数 `tmax` 写为离开参数。本分支传 `&exit_t` 到该位置，所以 `exit_t` 是**出口**，名称里不应写 entry。

## 5. 五道条件各防什么

`bounds` 存在：有有效盒可用。`contains(local_anchor)`：当前锚点在盒内，朝相机交点应解释为出口。`abs(determinant)>1e-20`：逆矩阵计算没有明显退化。`length_squared(local_direction)>1e-20`：射线有方向。求交成功且 `exit_t>0`：出口位于前进方向；透视时再要求 `exit_t<1`：出口在原点与相机之间。

任何条件不满足，代码保留原点锚点。保留原点可能继续被自身遮挡，但可以避免用无效数学结果把文字移到任意位置。

## 6. 正交视图有什么不同

正交视线平行。方向取 `state.camera_forward` 并转为本地；并没有一个对所有锚点都适用、满足 `t=1` 的具体相机位置，所以正交分支不施加 `exit_t<1` 的限制。

## 7. AABB 与真实几何

一个环形网格的 AABB 会盖住中间空洞。一条射线碰到盒面时，真实网格可能还很远，也可能根本没有表面。因此 AABB 锚点是轻量近似。凸壳比盒子贴合外轮廓，却仍不能表达凹洞；BVH 按实际三角形求交更准确，准备和逐实例查询成本也更高。

当前场景深度比较仍会参与最终显示判断；AABB 并没有直接决定“显示”，它只是改变比较使用的三维锚点。
