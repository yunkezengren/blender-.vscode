# 配色与图例约定

> 🔗 [返回索引](./README.md)

本目录的所有流程图遵循**统一的配色语义**。颜色不是装饰 —— **相同颜色的节点表示同一职责层**，让你可以跨文档建立直觉。

---

## 一、七色层级语义

```mermaid
flowchart LR
  U["① 用户界面层<br/>DNA / RNA / Python"] --> O["② Overlay 状态层<br/>State / Instance"]
  O --> A["③ 锚点与几何层<br/>AttributeTexts"]
  A --> T["④ 文本缓存层<br/>DRWTextStore"]
  T --> D["⑤ 深度层<br/>ViewDepths"]
  D --> P["⑥ 判定层<br/>投影与比较"]
  P --> R["⑦ 结果层<br/>绘制 / 剔除"]

  classDef ui fill:#DBEAFE,stroke:#2563EB,color:#1E3A8A,stroke-width:2px;
  classDef overlay fill:#EDE9FE,stroke:#7C3AED,color:#3B0764,stroke-width:2px;
  classDef geom fill:#CFFAFE,stroke:#0891B2,color:#164E63,stroke-width:2px;
  classDef text fill:#FEF3C7,stroke:#D97706,color:#78350F,stroke-width:2px;
  classDef depth fill:#D1FAE5,stroke:#059669,color:#064E3B,stroke-width:2px;
  classDef judge fill:#FCE7F3,stroke:#DB2777,color:#831843,stroke-width:2px;
  classDef result fill:#E0E7FF,stroke:#4F46E5,color:#1E1B4B,stroke-width:2px;

  class U ui;
  class O overlay;
  class A geom;
  class T text;
  class D depth;
  class P judge;
  class R result;
```

| 层 | 颜色 | 填充 / 描边 | 语义 | 典型节点 |
|----|------|-------------|------|----------|
| ① UI | 🔵 蓝 | `#DBEAFE` / `#2563EB` | 用户可见的开关、面板 | DNA 位标志、RNA 属性、Python 勾选框 |
| ② Overlay | 🟣 紫 | `#EDE9FE` / `#7C3AED` | 引擎实例与状态快照 | `Instance`、`State`、`draw_v3d` |
| ③ 几何 | 🩵 青 | `#CFFAFE` / `#0891B2` | 锚点计算与坐标变换 | `AttributeTexts`、偏移计算、AABB |
| ④ 文本 | 🟡 琥珀 | `#FEF3C7` / `#D97706` | 文本缓存与字符串 | `DRWTextStore`、`ViewCachedString` |
| ⑤ 深度 | 🟢 绿 | `#D1FAE5` / `#059669` | 深度数据与回读 | `ViewDepths`、`GPU_texture_read` |
| ⑥ 判定 | 🩷 粉 | `#FCE7F3` / `#DB2777` | 投影、比较、决策分支 | `text_anchor_project_with_depth` |
| ⑦ 结果 | 🟦 靛 | `#E0E7FF` / `#4F46E5` | 最终绘制或剔除 | `BLF_draw_default`、`IS_CLIPPED` |

## 二、状态色（语义固定）

这三个颜色**全局含义固定**，无论出现在哪个图里：

```mermaid
flowchart LR
  OK["✅ 正确 / 保留 / 通过"] --- WARN["⚠️ 需注意 / 有条件"] --- ERR["❌ 错误 / 剔除 / 危险"]

  classDef ok fill:#DCFCE7,stroke:#16A34A,color:#14532D,stroke-width:2px;
  classDef warn fill:#FEF9C3,stroke:#CA8A04,color:#713F12,stroke-width:2px;
  classDef err fill:#FEE2E2,stroke:#DC2626,color:#7F1D1D,stroke-width:2px;

  class OK ok;
  class WARN warn;
  class ERR err;
```

| 状态 | 填充 / 描边 | 含义 |
|------|-------------|------|
| ✅ 绿 | `#DCFCE7` / `#16A34A` | 正确、保留、通过测试、无需修改 |
| ⚠️ 黄 | `#FEF9C3` / `#CA8A04` | 需注意、有条件成立、建议改进 |
| ❌ 红 | `#FEE2E2` / `#DC2626` | 错误、被剔除、必须修复、陷阱 |

## 三、严重度色（仅用于问题清单）

| 标记 | 填充 / 描边 | 含义 |
|------|-------------|------|
| 🟠 必修 | `#FFEDD5` / `#EA580C` | 提交前必须处理 |

## 四、节点形状约定

```mermaid
flowchart LR
  R(["圆角矩形<br/>起点 / 终点"]) --> S["方框<br/>处理步骤"]
  S --> D{"菱形<br/>判断分支"}
  D -->|是| P[["双边框<br/>子流程 / 函数"]]
  D -->|否| DB[("圆柱<br/>数据存储")]
  P --> N>旗帜形<br/>外部输入]

  classDef ok fill:#DCFCE7,stroke:#16A34A,color:#14532D,stroke-width:2px;
  classDef warn fill:#FEF9C3,stroke:#CA8A04,color:#713F12,stroke-width:2px;
  classDef err fill:#FEE2E2,stroke:#DC2626,color:#7F1D1D,stroke-width:2px;
  classDef judge fill:#FCE7F3,stroke:#DB2777,color:#831843,stroke-width:2px;
  classDef depth fill:#D1FAE5,stroke:#059669,color:#064E3B,stroke-width:2px;

  class R,N ok;
  class D judge;
  class DB depth;
  class P warn;
  class S err;
```

| 形状 | Mermaid 语法 | 用途 |
|------|--------------|------|
| 圆角矩形 | `id(["文本"])` | 流程起点 / 终点 |
| 方框 | `id["文本"]` | 普通处理步骤 |
| 菱形 | `id{"文本"}` | 条件判断 |
| 双边框 | `id[["文本"]]` | 子流程 / 函数调用 |
| 圆柱 | `id[("文本")]` | 数据存储 |
| 旗帜 | `id>"文本"]` | 外部输入 |

## 五、线条语义

| 线型 | Mermaid 语法 | 含义 |
|------|--------------|------|
| 实线箭头 | `-->` | 控制流 / 顺序执行 |
| 虚线箭头 | `-.->` | 数据流 / 引用 / 借用 |
| 粗箭头 | `==>` | 关键路径 / 高开销操作 |
| 带标签 | `-->\|标签\|` | 条件分支、真/假 |
